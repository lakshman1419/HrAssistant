# Design Handoff

The screen uses a calm, enterprise green palette with a light layered background, compact serif title, and a single framed conversation workspace.

- Assistant messages sit left with a dark green mark and pale bubble.
- User messages sit right with a pale green avatar and dark green bubble.
- Suggestions appear only in the initial empty conversation state.
- The composer stays visually anchored below the scrollable message list.
- The layout collapses to edge-to-edge mobile without losing the status indicator or input affordance.
- Focus rings, semantic labels, live conversation announcements, and keyboard submission are included.
- Loading uses a distinct thinking bubble with animated dots; API failures become a friendly assistant message.
